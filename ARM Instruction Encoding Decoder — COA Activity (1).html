Instruction Encoding Decoder (ARM, 32-bit)

A machine instruction is just 32 bits. The decoder slices them into fields: condition, opcode, source registers, destination register and immediate.

Toddler version

The computer reads a strip of 32 little boxes, each holding a 0 or a 1. Some boxes together mean “what to do” (add? move?). Some mean “which toy boxes to use” (registers). Some are just a number. The decoder is the helper who reads the strip and says, “Aha, this means R1 = R2 + R3!”

Input

Type a hex value, pick a preset, or click any bit to flip it and watch the decoding change. Supported: data-processing, load/store (LDR/STR) and branch (B/BL).

How the decoder works

  1. Read bits 27–26 (and 27–25) to find the format: 00 data processing, 01 load/store, 101 branch.
  2. Read bits 31–28: the condition (1110 = AL, always).
  3. Slice the rest using that format’s layout: opcode, Rn, Rd, operand 2 / offset.
  4. Rebuild the assembly text and the register-transfer meaning.
